
## Overview

This repository contains a collection of research projects completed during my early research experience and over the years. These projects demonstrate applications of epidemiology, biomedical data science, machine learning, spatial analysis, statistical modeling, and data visualization using R and SAS.

The projects cover a range of topics in public health, environmental health, genomics, and clinical research and represent my progression in developing reproducible analytical workflows.

## Representative Projects

| Project | Description |
|---------|-------------|
